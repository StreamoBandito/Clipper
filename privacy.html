Clipper privacy policy

Last updated: November 14, 2026

Clipper is a private desktop app made by MWP Films for the Streamo Bandito channel. It is used only by the channel's own team, on their own computer.

What Clipper accesses

With the channel owner's permission (Google sign-in), Clipper reads the channel's own YouTube data through the YouTube Data API and YouTube Analytics API: the channel's videos, their view, like and comment counts, and comments on the channel's own videos. It uses read-only access.

How the data is used

The data is shown to the channel's team inside Clipper, on their own Mac, to see which videos perform well and to plan new videos. It is not used for advertising, not sold, and not shared with anyone, except that short text summaries may be sent to the Anthropic Claude API to help write video titles and captions.

Where the data is stored

On the team's own Mac only. Sign-in tokens are stored encrypted in the macOS Keychain. Clipper has no server and no user accounts.

Google API Services

Clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Clipper uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Disconnect YouTube in Clipper (Accounts), or remove Clipper's access at myaccount.google.com/permissions. Disconnecting deletes the stored token from the Mac.
